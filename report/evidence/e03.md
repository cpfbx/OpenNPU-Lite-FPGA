# D007-A2 first-K overwrite promotion decision

Decision date: 2026-09-24. Physical-board measurements: 2026-09-23.

## Decision and scope

D007-A2 is promoted as the current **dense-GEMM hardware baseline** after
the independent first-K overwrite gate. The previous D007-A tag
`d007a-board-validated-20260923` stays intact as the rollback point. This
decision covers one identified PYNQ-Z2, one verified BIT, MODE 7/9 dense
GEMM, numerical correctness, recovery, routed 100 MHz timing and 30-minute
mixed-shape stability. It does not establish KWS compatibility on this BIT,
power/energy improvement, cross-board reproduction, or D007-P/K results.

## Independent gates

| Gate | Physical result | Verdict |
| --- | --- | --- |
| 15x13x65 tail | 20/20 same-BIT MODE 7/9 exact cases | Pass |
| 512-cubed | 20/20 paired seeds; exact tile/matrix outputs and same 2,684,354,560 total effective MACs | Pass |
| Performance | MODE 7 4,239,808 vs MODE 9 3,977,664 PL cycles/matrix; exactly 262,144 cycles removed, above the 200,000-cycle gate | Pass |
| Recovery | Unsupported mode `0x07`, reset, then exact MODE 9/7/9 without BIT reload | Pass |
| Smoke | 60.012 s, 546 paired cases, zero mismatch/timeout/recovery/contract failure | Pass |
| Long stability | 1800.004 s, 18,509 paired cases, all seven configured shapes and two 512-cubed pressure cases; all four failure counts zero | Pass |
| Offline | 23 RTL testbenches and 171 Python unit tests pass; routed setup/hold timing positive | Pass |

In the same-BIT paired 512-cubed run, MODE 7 averaged 43.276 ms and MODE 9
40.675 ms for the DMA+PL window. The mean paired saving was 2.601 ms
(1.064x wall-time speedup); this is not full application end-to-end time.
The candidate removed only the pre-clear: the 30-minute cumulative
MODE 7/MODE 9 PL-cycle difference equals the MODE 7 clear count exactly
(`261,677,261` cycles). The long-run validator also checked identical
MACs and non-clear work, parallel counter closure, queue capacity and stable
CMA addresses. The work was not reduced to manufacture the speedup.

## Evidence custody and limits

The original board JSON, board verdicts, independent host verdicts, board
log, clean build identities and package identity are preserved in
`metrics/d007_a2_promotion_20260923/`. All 17 payload files match its
`SHA256SUMS.txt`. The three 30-minute files were compared byte-for-byte by
SHA-256 against the board before the local independent validator returned
`passed=true` with all 12 gates true. The board was not re-run for this
archive operation.

The 262,144-cycle reduction is an isolated MODE 7/9 result; no power meter
was used, so no J/matrix or nJ/MAC claim is made. The 120-sample KWS gate
must be rerun on the eventual submission BIT before claiming application
compatibility for that release. D007-P remains a separate, unverified
double-buffer experiment with its own correctness, timing and same-BIT A/B
stop gates.
