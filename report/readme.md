# 设计报告与技术资料

[详细设计报告PDF](design_report.pdf)与[Markdown正文](design_report.md)是同一份报告的两种格式。报告按设计机制、优化实验、应用接线和复现方法展开。

| 阅读目标 | 对应入口 |
|---|---|
| 背景、相关工作与设计贡献 | 详细报告第1章 |
| 系统原理、8×8阵列、分块与软硬件接口 | 详细报告第2–3章 |
| 硬件和主机优化、CPU对照及能量观察 | 详细报告第4–5章；[分阶段成果](development_results.md) |
| KWS单层、真实共享中段与完整PC图 | 详细报告第6章 |
| 团队判断、模型建议与实现纠错、Skill提炼 | 详细报告第7章和附录C；[技术协作案例](collaboration_interactions.md) |
| 下载、环境、PC运行、仿真、构建与板端复做 | [复现指南](../reproduction_guide.md)，详细报告第8章和附录B |
| 资源与时序原件、实板返回和波形 | [技术证据导航](evidence/readme.md)、[来源索引](technical_source_index.csv) |

证据目录保存各阶段的原始记录，日期和版本说明对应其形成时点；当前使用步骤以复现指南为准。公开交互按真实过程作编辑性归并，整理说明见技术协作案例。
